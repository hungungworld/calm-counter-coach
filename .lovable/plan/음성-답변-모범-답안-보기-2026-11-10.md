# 음성 답변 + 모범 답안 보기

## 1. 음성으로 답하기
- 대화 화면의 마이크 버튼을 누르면 녹음이 시작돼요. 버튼이 "녹음 중"으로 바뀌고, 다시 누르면 멈춰요.
- 녹음한 말은 AI가 글로 바꿔서 입력칸에 넣어 줘요. 직원이 확인·수정한 뒤 「보내기」를 눌러요 (바로 보내지 않음).
- 처음 쓸 때 휴대폰이 마이크 허용을 물어봐요. 거절하면 "마이크를 쓸 수 없어요. 글로 답해 주세요." 안내.
- 녹음 파일은 글로 바꾸는 데만 쓰고 저장하지 않아요.
- 녹음은 최대 30초. 남은 3분 시간은 녹음 중에도 계속 흘러요.

## 2. 모범 답안 보기
- 피드백 화면 아래에 「모범 답안 보기」 버튼 추가.
- 누르면 같은 상황에서 직원이 잘 응대한 예시 대화(손님 첫마디 + 직원 답 3번 정도)를 카드로 보여 줘요.
- 직원이 실제로 한 답 옆에 "이렇게 바꿔 보세요" 한 줄 비교도 함께 보여 줘요.
- 처음엔 접혀 있고, 누를 때만 불러와요 (기다리는 동안 "모범 답안을 만들고 있어요…").

## 기술 메모
- 음성: 브라우저 MediaRecorder로 녹음 → 서버 함수에 base64 전달 → `@lovable.dev/ai-gateway` `transcribeAudio` (기본 모델 openai/gpt-transcribe, 언어 ko). 용량 제한 검증.
- 모범 답안: 새 서버 함수 `getModelAnswer`, `generateResponse` + strict JSON schema `{ turns: [{customer, staff}], compare: [{yours, better}] }`. 기존 안전 규칙 재사용.
- 모델 타입 재생성(gpt-transcribe 추가), 오류는 기존 `{ ok, error }` 한국어 메시지 방식.
- 녹음 길이 제한 규칙을 roleplay-rules에 두고 테스트 추가.
